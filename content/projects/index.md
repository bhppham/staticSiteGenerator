## Othello Game

[Github](https://github.com/bhppham/othello)

This project started as an introductory course to AI where my team created othello playing script. The script used terminal inputs as player moves. Then after the course, I created a web user interface. Instead of playing in the terminal now the player had a visual representation of the board and could play directly on the website.

## VIsQuiz

[Published Paper](https://arxiv.org/abs/2207.09534)

This was my major qualifying project where I got to do and learn so much. Another full-stack engineering project about data visualization, where I worked on the quiz website that stored the run of each participant in the database and visualized the graphics as they interacted with the quiz. Further, I analyzed the data gathered from the quiz and was able to draw some conclusions about accuracy development in graphical interpretation. More in the published paper linked above.
